## Core idea
Apply the Turbulent Displace effect to an adjustment layer to create a wavy, displacement-based distortion that makes the image shimmer and warp. Keyframe the Amount and Size parameters over multiple frames at regular intervals to create a pulsing, turbulent animation. The result shows the character displaced and glowing with a chaotic, energetic visual effect—useful for transition effects, magical moments, or impact moments.

## Rebuild recipe (from scratch)
1. Bring in clip with character/footage (in this case, anime character).
2. Create an Adjustment Layer above the clip: Layer > New > Adjustment Layer.
3. On adjustment layer, add Turbulent Displace effect: Effects > Distort > Turbulent Displace.
4. Set initial Turbulent Displace properties (visual feedback):
   - Amount: ~100-150 (start with moderate displacement)
   - Size: start with ~33-150, plan to reach 400 at peak
   - Offset: Leave at default or randomize
   - Complexity: ~5-6 (moderate detail)
   - Evolution: Event or Time (time-based recommended for animation)
   - Iterations: Pro All (maximum quality)
   - Antialiasing for Best: Low (faster render)
5. Create keyframes for both Amount and Size at clip start (frame 0): Set starting values (~100-150 for Amount, ~33 for Size).
6. Move forward 4 frames (frame 4); increase Amount and Size values; create new keyframes.
7. Repeat step 6 multiple times throughout clip duration (every 4 frames), progressively increasing Size up to 400 at peak.
8. Play through to preview: effect should pulse/warp rhythmically as turbulent displacement increases and decreases.
9. Fine-tune keyframe spacing (e.g., use 4-frame intervals consistently) and values (Amount, Size) based on desired intensity and timing.
